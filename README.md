# Job-app
This is a site for applying for jobs and upload new jobs
A modern web application that allows users to post job listings and others to browse, view details, and apply via email or external links.

## Features

-  Post a job with company, category, type, and salary.
-  Browse available jobs with detailed views.
-  Built with React and TailwindCSS for a clean and responsive UI.
